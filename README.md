# Diorama Descent

Hybrid Godot project built from:

- Diorama of Descension for the slash combat, sprite characters, and background language.
- SteamPile for the action highlighting and procedural map generation feel.

## Current Setup

- Fresh project copy in `Documents/GodotProjects`.
- SteamPile source files live in the project root.
- Diorama source bundle is mirrored locally in `assets/legacy/diorama-of-descension/`.
- Landscape presentation is the default.

## Game Direction

- 3D world, sprite characters.
- Grid-based opening movement.
- Goblin enemies telegraph their movement.
- Clash triggers free hits depending on approach angle.
- Close combat uses swipe-directed slash animations.
- Left-side joystick controls movement and dodge.
